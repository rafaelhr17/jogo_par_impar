# jogo_par_impar
Projeto simples criado com o intuito de desenvolver minhas habilidades de codificação e lógica da programação em python. Neste projeto você jogará "par ou ímpar", sendo seu adversário o computador, e quanto mais vitórias consecutivas, mais pontos acumulará, e caso perca, poderá salvar sua pontuação. (Não utilizei IA generativa no projeto)
